# 生图后端：小型 SD 本机部署或已有 API 接入并真实出图

新增独立 kb_images.py 或同等小模块，实现 provider 接口、配置和 doctor/smoke 命令。检查硬件后依据官方文档选兼容的小型 SD 模型，实际下载/安装到缓存；或使用已有 API 凭证。遵守上下文下载/调用上限。至少实际生成并检查一张 512 级图片，记录尺寸、时间、模型、下载大小、许可证和运行命令；离线 fake 测试不能充当真实成功。未具备条件时记录具体阻塞，同时实现无需生图的渐变/排版回退。不得下载完整大模型套装或修改全局 Python 环境，依赖放独立环境。

共同约束与验收要求见 00-context.md（管理器会注入）。
